OTA Business Desktop 1.9.0.

## What's new
- **Automatic encrypted backups** (Sync & Cloud → Backups):
  - The app backs up once a day and again on close if anything changed.
  - Backups go to `Documents/OTA Backups` by default, or to a folder you choose (USB, Google Drive or OneDrive).
  - The last 14 are kept, which you can change. The last backup time is shown, and **Restore…** puts a backup back after taking a safety copy first.
  - Backups are AES-256 encrypted zips. Write down the backup password the app shows (*Show* / *Copy*): any 7-Zip, WinZip or Keka can open a backup with it.
- **Optional PIN lock** (Sync & Cloud → Security):
  - The app locks on start and after a chosen idle time.
  - After 5 wrong PINs, entry pauses.
  - *Forgot PIN?* checks your account password online.
- **Faster sync on slow connections:**
  - Compressed downloads, paging for big pulls and fewer round trips.
  - A sync with nothing new now takes about 2 s instead of over a minute on a slow line.
- **Smaller download:** the bundled database server now carries only what OTA needs. The Mac disk image went from 146 MB to 97 MB.
- The self-test now also checks secure connections to GitHub and the cloud, and PDF/Excel export.

Windows and Mac users get this version through the in-app update prompt. A backup of the local database is taken before installing. If you are on 1.2.1 or older, install this version once by hand.

**Mac: first start of a new install.** The app is not signed by Apple, so macOS blocks it the first time. Choose *Done*, open *System Settings > Privacy & Security*, click **Open Anyway** next to OTA Business and confirm. Start it from Applications, not from the disk image.

Windows may show a SmartScreen warning because the installer is not code-signed: choose *More info* > *Run anyway*.
