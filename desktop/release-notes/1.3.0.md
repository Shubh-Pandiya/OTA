OTA Business for Windows 1.3.0.

## What's new
- **Automatic updates.** The app checks for new versions when it starts and every few hours, then asks *Update now* or *Later* and shows what's new.
- **Your data is protected during updates.**
  - The app sends unsynced work to the cloud first. If you're offline, that work stays safely on this laptop and uploads later.
  - It backs up the whole local database before installing, keeping the last 5 backups in `%LOCALAPPDATA%\OTA Business Data\backups`.
  - It checks the download against its published SHA-256 before installing.
- **Safer startup.** The app refuses to open data from a newer version. It applies database changes all at once or not at all.
- *Sync & Cloud → App version* shows the installed version, lets you check for updates, and opens the backups folder.

## Coming from 1.2.1 or older
Install this version once by hand: download **OTA-Business-1.3.0.msi** below and run it. Your data folder is not touched. Later versions update themselves.

Windows may show a SmartScreen warning because the installer is not code-signed: choose *More info* > *Run anyway*.
