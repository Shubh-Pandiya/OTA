OTA Business Desktop 1.7.0.

## What's new
- **Mac updates download again.** On networks with IPv6 the Mac app timed out before the download started ("HTTP connect timed out"). The app now connects over IPv4, and a dropped download resumes where it stopped (up to 4 tries) instead of starting over.
- **Sharper Insights charts on Mac.** "Orders over time", "Payments over time" and the other charts are sized for Retina screens: date labels no longer overlap the axis, and lines, dots and bars are full size.
- **Test login on the desktop.** testuser1@ota.com can sign in on any laptop. Its data is kept apart from the real data on the laptop: while it is signed in only test orders, bills, advices, Insights and search results show, and the real data comes back untouched at the next staff login. Nothing is deleted or mixed when switching.
- **Accounts for the test user.** The test login has its own Accounts books (chart, vouchers, ledgers, commission) built from test bills only. The real books never include test data. Cloud clean-up stays admin-only.

**Mac users on 1.5.0–1.6.1:** if the in-app update fails with a timeout, download `OTA-Business-1.7.0-mac-arm64.dmg` from the release page once and drag it to Applications. Later updates work in the app.

Windows and Mac users get this version through the in-app update prompt. A backup of the local database is taken before installing. If you are on 1.2.1 or older, install this version once by hand.

**Mac: first start of a new install.** The app is not signed by Apple, so macOS blocks it the first time. Choose *Done*, open *System Settings > Privacy & Security*, click **Open Anyway** next to OTA Business and confirm. Start it from Applications, not from the disk image.

Windows may show a SmartScreen warning because the installer is not code-signed: choose *More info* > *Run anyway*.
