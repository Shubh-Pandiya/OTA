OTA Business Desktop 1.5.0.

## What's new
- **Mac app.** OTA Business now runs on Apple-silicon Macs, with the same database, backups and in-app updates as on Windows. Download **OTA-Business-1.5.0-mac-arm64.dmg**, open it and drag OTA Business to Applications.
- **Admins.** Only varun@ota.com and shubham@ota.com can clean up the cloud (archive, purge, retention) or open **Accounts**. The cloud enforces this too. Other staff can use everything else.
- **Test account kept apart.** Data entered by testuser1@ota.com is hidden from everyone else and never counts in totals, Insights, Accounts or exports. Test orders and advices have their own number series. The test login gets a **Clear all my test data** button under *Sync & Cloud*.
- Earlier test orders, advices and bills were removed from the cloud, and the order and advice numbers continue from the last real one.

Windows users get this version through the in-app update prompt. If you are on 1.2.1 or older, install 1.3.0 or this version once by hand first.

**Mac: first start.** The app is not signed by Apple, so macOS blocks it the first time. Choose *Done*, open *System Settings > Privacy & Security*, click **Open Anyway** next to OTA Business and confirm. Start it from Applications, not from the disk image. Later versions update themselves.

Windows may show a SmartScreen warning because the installer is not code-signed: choose *More info* > *Run anyway*.
