OTA Business Desktop 1.6.0.

## What's new
- **Deleting is permanent and asks first.** Deleting an order, bill, payment advice, advice line, order–bill link, buyer, supplier, to-do, voucher or account, or clearing test data, now shows a confirmation that names what goes and says it can't be undone. Cancel / **Delete** (red).
- **Hard deletes everywhere.** A deleted item is removed from this laptop, the cloud, the phones and the other laptops; nothing is kept as "deleted" any more. Items that were deleted before are cleaned out on the first start.
- **No coming back.** A phone or laptop that was offline can't bring a deleted item back. An edit made elsewhere *after* the delete still wins.
- **Accounts vouchers** are deleted completely. The audit log keeps a single line: who deleted which voucher number, and when.
- A retention purge is still not a delete: the laptop keeps purged rows.

Windows and Mac users get this version through the in-app update prompt. A backup of the local database is taken before installing. If you are on 1.2.1 or older, install this version once by hand.

**Mac: first start of a new install.** The app is not signed by Apple, so macOS blocks it the first time. Choose *Done*, open *System Settings > Privacy & Security*, click **Open Anyway** next to OTA Business and confirm. Start it from Applications, not from the disk image.

Windows may show a SmartScreen warning because the installer is not code-signed: choose *More info* > *Run anyway*.
