**OTA Business 2.0.0: the new phone app** (package `com.ota.business`, signed with the OTA release key).

- Install it with **Move now** in the old app (1.2.0). Your orders, bills, advices, to-dos, pictures and settings come across, and you only need to sign in once.
- If the move was interrupted: on the sign-in screen choose **Moving from the old app?**, pick the file in *Download/OTA Business* and type the recovery code the old app shows.
- **App lock:** a PIN, with fingerprint as an option (Sync Settings → Security). The app locks when it opens and after being away for the time you choose.
- **Encrypted storage:** the databases and pictures on the phone are encrypted, with keys kept in the Android Keystore.
- **Faster sync on slow networks:** compressed downloads, paging for big pulls and fewer round trips.
- Updates now come only from `phone-v` releases signed with the OTA release key; anything else is refused.
